## Summary

Implemented the complete Diff Engine for PetalTrace (Phase 5). This includes structural comparison of execution paths, content diffing with similarity scores, token and cost comparison, a CLI command for comparing runs, and REST API endpoints for computing and retrieving diffs. Diffs can be cached in the database for fast retrieval.

## Motivation

The Diff Engine enables:
1. Comparing two workflow runs to identify differences in execution paths
2. Detecting when graph structure diverges (nodes added/removed)
3. Computing text diffs for LLM outputs with similarity scoring
4. Analyzing token and cost changes between runs
5. Debugging prompt changes and their effects on outputs
6. A/B testing different prompts or model configurations

## What Changed

### New Additions

**diff/structural.go** — Structural comparison
- `StructuralDiffer` — compares execution paths between runs
- `CompareGraphs(baseSpans, compareSpans)` — detects nodes added/removed, edges changed
- `HasPathDivergence(graphDiff)` — checks if paths differ
- `MatchNodes(baseSpans, compareSpans)` — pairs spans by node ID
- `NodeMatch` struct with `MatchStatus` (both, base_only, compare_only)

**diff/content.go** — Text comparison
- `ContentDiffer` — compares text content with unified diff format
- `CompareText(baseText, compareText)` — generates diff hunks and similarity score
- `ComputeSimilarity(a, b)` — Levenshtein distance ratio (0.0 to 1.0)
- `ComparePrompts(baseSpan, compareSpan)` — compares LLM prompts
- `CompareOutputs(baseSpan, compareSpan)` — compares LLM completions
- Uses longest common subsequence (LCS) for line-level diff

**diff/cost.go** — Token and cost comparison
- `CostDiffer` — compares token usage and costs
- `CompareRuns(baseRun, compareRun)` — computes overall cost diff with breakdowns
- `CompareTokens(baseSpan, compareSpan)` — per-span token comparison
- `AggregateTokenDiffs(diffs)` — aggregates multiple token diffs
- `TokenAggregates` with `PercentChange()` and `CostPercentChange()`

**diff/engine.go** — Orchestration
- `Engine` — orchestrates all diff components
- `ComputeDiff(ctx, baseRunID, compareRunID, opts)` — computes complete diff
- `DiffOptions` — configures what to include (content, inputs, caching)
- `GetDiff(ctx, diffID)` — retrieves cached diff by ID
- `GetDiffByRuns(ctx, baseRunID, compareRunID)` — retrieves by run pair

**cmd/petaltrace/diff.go** — CLI command
- `petaltrace diff <base_run_id> <compare_run_id>` — compare two runs
- `--include-content` — include full text diffs
- `--include-inputs` — include input/output data diffs
- `--format table|json|summary` — output format
- `--output` / `-o` — write to file
- `--no-cache` — skip cache

**api/diff.go** — REST API endpoints
- `POST /api/diff` — compute or retrieve diff
- `GET /api/diff/{id}` — get cached diff by ID
- `GET /api/diff/runs` — get diff by run IDs
- `GET /api/diffs` — list diffs (shows count)

## Technical Specification

### Data Types

```go
// DiffOptions configures diff computation
type DiffOptions struct {
    IncludeContent    bool // Include full text diffs
    IncludeSimilarity bool // Compute similarity scores
    IncludeInputs     bool // Include input/output data diffs
    CacheResult       bool // Store result in database
}

// NodeMatch represents a matched pair of spans
type NodeMatch struct {
    NodeID      string
    NodeType    string
    Status      MatchStatus  // both, base_only, compare_only
    BaseSpan    *store.Span
    CompareSpan *store.Span
}

// TokenAggregates holds aggregated token statistics
type TokenAggregates struct {
    TotalBaseTokens     int
    TotalCompareTokens  int
    TotalDelta          int
    BaseInputTokens     int
    CompareInputTokens  int
    BaseOutputTokens    int
    CompareOutputTokens int
    TotalBaseCost       float64
    TotalCompareCost    float64
    CostDelta           float64
}
```

### API Endpoints

```
POST /api/diff
Request body: {
    "base_run_id": "run-abc123",
    "compare_run_id": "run-def456",
    "include_content": true,
    "include_inputs": false,
    "no_cache": false
}
Response: RunDiff

GET /api/diff/{id}
Response: RunDiff

GET /api/diff/runs?base_run_id=X&compare_run_id=Y
Response: RunDiff

GET /api/diffs
Response: { "total_diffs": 42, "message": "..." }
```

### CLI Interface

```
petaltrace diff <base_run_id> <compare_run_id> [flags]

Flags:
  --include-content    Include full text diffs for prompts and outputs
  --include-inputs     Include input/output data diffs
  --format string      Output format: table, json, or summary (default "table")
  -o, --output string  Write output to file
  --no-cache          Don't use or store cached diff results
```

### Go Package API

```go
// Create diff engine
engine := diff.NewEngine(traceStore)

// Configure options
opts := diff.DiffOptions{
    IncludeContent:    true,
    IncludeSimilarity: true,
    IncludeInputs:     false,
    CacheResult:       true,
}

// Compute diff
runDiff, err := engine.ComputeDiff(ctx, "run-abc", "run-def", opts)
if err != nil {
    return err
}

// Access results
fmt.Printf("Status match: %v\n", runDiff.Summary.StatusMatch)
fmt.Printf("Token delta: %+d\n", runDiff.Summary.TokenDelta)
fmt.Printf("Cost delta: $%+.6f\n", runDiff.Summary.CostDelta)

for _, nodeDiff := range runDiff.NodeDiffs {
    fmt.Printf("Node %s: %s\n", nodeDiff.NodeID, nodeDiff.Status)
}
```

```bash
petaltrace diff run-abc123 run-def456 --include-content --format table
```

### Example: Compute diff via API

```bash
curl -X POST "http://localhost:8090/api/diff" \
  -H "Content-Type: application/json" \
  -d '{
    "base_run_id": "run-abc123",
    "compare_run_id": "run-def456",
    "include_content": true
  }'
```

### Example: Retrieve cached diff

```bash
curl "http://localhost:8090/api/diff/diff-xyz789"
```

## Integration Notes

The Diff Engine integrates with:

1. **Store** — Uses `TraceStore` for run/span retrieval and diff caching
2. **RunDiff model** — Uses existing `store.RunDiff` and related types defined in Phase 1
3. **API** — New endpoints added to the HTTP API server
4. **CLI** — New `diff` command added to the CLI

The diff caching mechanism stores computed diffs in the `diffs` table, allowing fast retrieval of previously computed comparisons. The cache key is the combination of base and compare run IDs.
