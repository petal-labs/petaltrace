## Summary

Implemented the OTLP collector that receives traces via HTTP (port 4318) and gRPC (port 4317), classifies spans by kind, correlates them to workflow runs, enriches LLM spans with cost estimates, extracts text for full-text search, and persists data in batches. This enables PetalTrace to ingest traces from PetalFlow and any OpenTelemetry-instrumented application.

## Motivation

PetalTrace needs to receive traces from multiple sources using the standard OpenTelemetry protocol. The collector must classify spans to extract structured data (LLM prompts, tool invocations, node executions), group them into workflow runs, and enrich them with computed fields like cost estimates before persisting to the store.

#### Span Classifier (`collector/classifier.go`)
```go
type Classifier struct{}

func NewClassifier() *Classifier
func (c *Classifier) ClassifySpan(in *IngestedSpan) *store.Span
```

Classification rules:
1. `gen_ai.system` or `gen_ai.request.model` → LLM span
2. `petalflow.node.id` or `petalflow.node.type` → Node span
3. `tool.name` or `petalflow.tool.name` → Tool span
4. `petalflow.edge.source` or `petalflow.edge.target` → Edge span
5. Span name contains "llm", "chat", "completion", "generate" → LLM span
6. Span name contains "tool", "function_call" → Tool span
7. Default → Custom span

Extracts kind-specific payloads:
- LLM: provider, model, system_prompt, messages, completion, tokens, latency, cache usage
- Node: node_id, node_type, inputs, outputs, config, retry_count
- Tool: tool_name, action_name, origin, inputs, outputs, invoked_by
- Edge: source_node, source_port, target_node, target_port, data_size

- "OpenAI", "OPENAI", "open_ai" → "openai"

## Technical Specification

### API Endpoints

#### OTLP HTTP
- **Method**: POST
- **Path**: `/v1/traces`
- **Content-Type**: `application/x-protobuf`
- **Request Body**: `ExportTraceServiceRequest` protobuf
- **Response**: `ExportTraceServiceResponse` protobuf
- **Max Body Size**: 64MB

#### Health Check
- **Method**: GET
- **Path**: `/health`
- **Response**: `{"status":"ok"}`

### Go Package API

```go
// Create and start collector
collector, err := collector.NewCollector(collector.CollectorConfig{
    Store:        store,
    PricingTable: pricingTable,
    HTTPAddr:     ":4318",
    GRPCAddr:     ":4317",
})
if err != nil {
    return err
}

ctx := context.Background()
if err := collector.Start(ctx); err != nil {
    return err

// Get statistics
stats := collector.Stats()
fmt.Printf("Received: %d, Written: %d\n", stats.SpansReceived, stats.SpansWritten)
```

## Usage Examples

### Sending Traces via HTTP
```bash
# Using curl with OTLP protobuf
curl -X POST http://localhost:4318/v1/traces \
  -H "Content-Type: application/x-protobuf" \
  --data-binary @traces.pb
```

### Sending Traces via gRPC (Go SDK)
```go
import (
    "go.opentelemetry.io/otel"
    "go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc"
)

exporter, _ := otlptracegrpc.New(ctx,
    otlptracegrpc.WithEndpoint("localhost:4317"),
    otlptracegrpc.WithInsecure(),
)
```

### LLM Span with Cost Calculation
```go
// OTel attributes that trigger LLM classification and cost enrichment
span.SetAttributes(
    attribute.String("gen_ai.system", "anthropic"),
    attribute.String("gen_ai.request.model", "claude-sonnet-4-20250514"),
    attribute.Int64("gen_ai.usage.input_tokens", 1000),
    attribute.Int64("gen_ai.usage.output_tokens", 500),
    attribute.Int64("gen_ai.usage.cache_read_input_tokens", 200),
    attribute.String("gen_ai.system_prompt", "You are helpful."),
    attribute.String("gen_ai.completion", "Here is my response..."),
)
// Cost computed: (1000 * $3 + 500 * $15 + 200 * $0.30) / 1M ≈ $0.0106
```

### PetalFlow Run Correlation
```go
// Attributes that enable run correlation
span.SetAttributes(
```

## Integration Notes

**PetalFlow Integration**:
- The `traceflow/` adapter emits spans with `petalflow.*` attributes
- Root spans include graph, input, and config snapshots
- Node spans include `petalflow.node.id` and `petalflow.node.type`

**Iris Integration**:
- The OTel hook emits `gen_ai.*` semantic convention attributes
- LLM spans are automatically classified and enriched with costs

**Downstream Components**:
- The HTTP API (Phase 4) will query the store populated by this collector
- The CLI (Phase 3) will display runs and spans stored here
