## Summary

Implemented the complete HTTP API server for PetalTrace (Phase 4). This includes run management endpoints, prompt inspection, cost analysis, real-time SSE streaming for live workflow monitoring, and system health/stats/pricing endpoints. The API uses Go 1.22+ standard library routing with middleware for CORS, logging, and panic recovery.

## Motivation

The HTTP API enables:
1. The embedded React UI to query and display trace data
2. External tools and scripts to programmatically access run information
3. Real-time monitoring of running workflows via SSE
4. Cost analysis across runs, workflows, and time periods
5. Full prompt/completion inspection for debugging LLM interactions

## What Changed

### New Additions

**api/server.go** — Core API server setup
- `Server` struct with store, pricing table, logger, and HTTP server
- `ServerConfig` for configuration
- `NewServer(cfg ServerConfig) *Server` — creates new API server
- `Start(ctx context.Context) error` — starts HTTP server
- `Stop() error` — graceful shutdown
- Middleware: `loggingMiddleware`, `corsMiddleware`, `recoveryMiddleware`
- Helper types: `PaginatedResponse`, `SSEEvent`, `APIError`
- Helper methods: `writeJSON`, `writeError`, `writeAPIError`, `writeSSE`

**api/runs.go** — Run and span management
- `GET /api/runs` — list runs with filtering (workflow, status, since, until, min_cost, starred, pagination)
- `GET /api/runs/{id}` — get single run (optional `include_spans=true`)
- `DELETE /api/runs/{id}` — delete run and cascaded spans
- `GET /api/runs/{id}/spans` — get span tree (optional `kind` and `node` filters)
- `GET /api/runs/{id}/spans/{spanId}` — get single span
- `GET /api/runs/{id}/graph` — get graph snapshot with node execution status overlay

**api/prompts.go** — LLM prompt inspection
- `GET /api/runs/{id}/prompts/{nodeId}` — full LLM interaction data
- Returns: system prompt, messages, tool definitions, completion, tokens, timing, cache info

**api/cost.go** — Cost analysis
- `GET /api/cost/summary` — aggregate cost metrics (total tokens, cost, grouped by workflow/provider/model)
- `GET /api/cost/runs/{id}` — per-run cost breakdown with node-level detail
- `GET /api/cost/timeseries` — time-bucketed cost data for charts (configurable bucket size)

**api/live.go** — Real-time streaming
- `GET /api/runs/{id}/stream` — SSE for single run updates (span events, completion)
- `GET /api/live` — SSE for all active runs (new runs, status changes, heartbeats)
- `LiveEventBroadcaster` — pub/sub system for SSE clients

**api/system.go** — System endpoints
- `GET /api/health` — health check with store connectivity status
- `GET /api/stats` — database and runtime statistics
- `GET /api/pricing` — current pricing table (list all or filter by provider/model)
- `PUT /api/pricing` — update pricing entries

## Technical Specification

### API Endpoints

#### Run Endpoints

```
GET /api/runs
Query params:
  - workflow: string (filter by workflow name)
  - workflow_id: string (filter by workflow ID)
  - status: string (running|completed|failed)
  - since: RFC3339 or duration (e.g., "24h", "7d")
  - until: RFC3339 or duration
  - min_cost: float64 (minimum estimated cost)
  - starred: bool (filter starred runs)
  - cursor: string (pagination cursor)
  - limit: int (default 50)
  - sort_by: string (field to sort by)
  - sort_order: string (asc|desc)
Response: PaginatedResponse { data: []Run, cursor: string, has_more: bool }

GET /api/runs/{id}
Query params:
  - include_spans: bool (include full span tree)
Response: Run | { run: Run, spans: []Span }

DELETE /api/runs/{id}
Response: { status: "deleted", run_id: string }

GET /api/runs/{id}/spans
Query params:
  - kind: string (llm|node|tool|edge|custom)
  - node: string (filter by node ID)
Response: []Span

GET /api/runs/{id}/spans/{spanId}
Response: Span

GET /api/runs/{id}/graph
Response: { run_id: string, graph_snapshot: object, node_statuses: map[string]NodeStatus }
```

#### Prompt Endpoint

```
GET /api/runs/{id}/prompts/{nodeId}
Response: {
  span_id: string,
  run_id: string,
  node_id: string,
  node_type: string,
  name: string,
  provider: string,
  model: string,
  prompt: {
    system_prompt: string,
    messages: []LLMMessage,
    tool_definitions: []ToolDefinition,
    temperature: float64,
    max_tokens: int
  },
  completion: {
    content: any,
    text_content: string,
    stop_reason: string
  },
  tokens: {
    input_tokens: int,
    output_tokens: int,
    total_tokens: int,
    cost_estimate: float64,
    cache_read_tokens: int,
    cache_write_tokens: int
  },
  timing: {
    started_at: timestamp,
    completed_at: timestamp,
    duration_ms: int64,
    time_to_first_token_ms: int64,
    total_latency_ms: int64
  }
}
```

#### Cost Endpoints

```
GET /api/cost/summary
Query params:
  - since: RFC3339 or duration (default 7d)
  - until: RFC3339 or duration
  - group_by: string (workflow|provider|model)
Response: {
  since: timestamp,
  until: timestamp,
  total_runs: int,
  total_tokens: int64,
  total_cost: float64,
  input_tokens: int64,
  output_tokens: int64,
  cache_read_tokens: int64,
  cache_write_tokens: int64,
  by_workflow: map[string]CostGroup,
  by_provider: map[string]CostGroup,
  by_model: map[string]CostGroup
}

GET /api/cost/runs/{id}
Response: {
  run_id: string,
  workflow_name: string,
  total_tokens: TokenSummary,
  estimated_cost: CostEstimate,
  llm_calls: int,
  by_node: []NodeCostBreakdown
}

GET /api/cost/timeseries
Query params:
  - since: RFC3339 or duration (default 7d)
  - until: RFC3339 or duration (default now)
  - bucket: string (duration, default "1h", supports "d" suffix for days)
Response: {
  since: timestamp,
  until: timestamp,
  bucket_size: string,
  data_points: []{ timestamp, runs, tokens, cost }
}
```

#### SSE Streaming Endpoints

```
GET /api/runs/{id}/stream
SSE Events:
  - event: run, data: Run (initial + updates)
  - event: spans, data: []Span (initial tree)
  - event: span, data: Span (new span added)
  - event: done, data: { status: string }
  - event: error, data: { error: string }

GET /api/live
SSE Events:
  - event: init, data: { active_runs: []Run }
  - event: run_started, data: Run
  - event: run_updated, data: Run
  - event: run_completed, data: { run_id: string }
  - event: heartbeat, data: { timestamp: int64, active_count: int }
```

#### System Endpoints

```
GET /api/health
Response: {
  status: "healthy"|"degraded",
  timestamp: timestamp,
  version: string,
  details: map[string]string
}

GET /api/stats
Response: {
  database: {
    size_bytes: int64,
    run_count: int64,
    span_count: int64,
    diff_count: int64,
    oldest_run: timestamp,
    newest_run: timestamp
  },
  top_workflows: []{ workflow_name, run_count },
  runtime: {
    go_version: string,
    num_goroutine: int,
    num_cpu: int,
    alloc_bytes: uint64,
    total_alloc_bytes: uint64,
    sys_bytes: uint64
  }
}

GET /api/pricing
Query params:
  - provider: string (optional, filter by provider)
  - model: string (optional, requires provider, get specific entry)
Response (list): {
  entries: []PricingEntry,
  by_provider: map[string][]PricingEntry,
  updated_at: timestamp
}
Response (specific): PricingEntry

PUT /api/pricing
Request body: {
  provider: string (required),
  model: string (required),
  input_per_1m: float64,
  output_per_1m: float64,
  cache_read_per_1m: float64,
  cache_write_per_1m: float64
}
Response: { status: "updated", entry: PricingEntry }
```

### Go Package API

```go
// Server configuration
type ServerConfig struct {
    Store        store.TraceStore
    PricingTable *pricing.PricingTable
    Logger       *slog.Logger
    Addr         string  // default ":8090"
}

// Create and start server
server := api.NewServer(api.ServerConfig{
    Store:        traceStore,
    PricingTable: pricingTable,
    Logger:       logger,
    Addr:         ":8090",
})
server.Start(ctx)
defer server.Stop()
```

## Usage Examples

### Example: List recent failed runs

```bash
curl "http://localhost:8090/api/runs?status=failed&since=24h&limit=10"
```

### Example: Get full prompt for an LLM node

```bash
curl "http://localhost:8090/api/runs/run-abc123/prompts/generate_response"
```

### Example: Subscribe to live run updates

```bash
curl -N "http://localhost:8090/api/runs/run-abc123/stream"
# Receives SSE events as the run progresses
```

### Example: Get cost summary grouped by model

```bash
curl "http://localhost:8090/api/cost/summary?since=7d&group_by=model"
```

### Example: Update pricing for a model

```bash
curl -X PUT "http://localhost:8090/api/pricing" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "anthropic",
    "model": "claude-3-opus-20240229",
    "input_per_1m": 15.0,
    "output_per_1m": 75.0
  }'
```

## Integration Notes

The HTTP API is designed to serve the embedded React UI (Phase 8). Key integration points:

1. **CORS enabled** — allows UI served from different ports during development
2. **SSE streaming** — enables real-time timeline updates without polling
3. **Pagination** — cursor-based pagination for efficient large dataset handling
4. **Graph overlay** — combines static graph snapshot with runtime node status

The API uses the same `store.TraceStore` interface as the CLI commands, ensuring data consistency.
