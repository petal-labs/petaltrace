## Summary

Completed the PetalTrace React UI by implementing the missing pages and components: Cost Dashboard with charts, Diff View with side-by-side comparison, and Graph View with React Flow. The UI now provides full visualization capabilities for workflow runs, cost analytics, run comparisons, and execution graph topology.

## Motivation

The UI is essential for:
1. Visual inspection of workflow execution timelines
2. Cost analytics and trend visualization
3. Comparing runs to identify regressions or improvements
4. Graph-based understanding of workflow topology
5. Interactive prompt inspection and replay configuration

## What Changed

### New Additions

**ui/src/pages/CostDashboard.tsx** — Cost analytics dashboard
- Summary cards: Total cost, tokens, runs, cost per 1K tokens
- Cost trend indicator (up/down vs. start of period)

## Technical Specification

### CostDashboard Component

Uses recharts for all visualizations:
- `AreaChart` for time series (cost, tokens)
- `PieChart` for workflow breakdown
- `BarChart` for provider/model breakdown

Props pulled from API:
- `getCostSummary()` — Aggregate metrics with breakdowns
- `getCostTimeseries()` — Time series data points

### DiffView Component

Diff computation flow:
1. Check for cached diff via `getDiffByRuns()`
2. If not cached, compute via `computeDiff()` mutation
3. Display summary, node diffs, cost comparison

Node diff rendering:
- Collapsible rows with expand/collapse toggle
- Red highlight for base output, green for compare output
- Delta indicators with color coding

### GraphView Component

React Flow configuration:
- Custom node type with stats overlay
- Smooth step edges with arrow markers
- Auto-fit view on load
- Mini-map with status-colored nodes

Node data structure:
```typescript
interface NodeData {
  span: Span
  stats?: {
    tokens: number
    cost: number
    llmCount: number
    toolCount: number
  }
  selected: boolean
  onClick: () => void
}
```

## Usage Examples

### Example: Viewing Cost Dashboard

Navigate to `/cost` to see:
- Summary metrics for selected time range
- Trend visualization
- Breakdown by workflow, provider, and model

### Example: Comparing Two Runs

1. Navigate to `/diff`
2. Select base run from dropdown
3. Select compare run from dropdown
4. Click "Compare Runs"
5. View summary and expand nodes to see output diffs

### Example: Viewing Workflow Graph

1. Navigate to `/runs/{runId}`
2. Click "Graph" tab
3. Interact with nodes:
   - Click to select (opens PromptInspector for LLM spans)
   - Drag to reposition
   - Scroll to zoom
   - Use mini-map for navigation

## Integration Notes

All UI components integrate with:
- **HTTP API** — All data fetched via `/api/*` endpoints
- **React Query** — Caching, refetching, loading states
- **SSE** — Live updates for running workflows
- **React Router** — URL-based navigation

The UI is designed to work with the daemon API on `localhost:8090`. In production, a reverse proxy would serve both the UI and API on the same origin.
