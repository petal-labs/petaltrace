## Summary

Implemented the foundation layer for PetalTrace including the Go module scaffolding, configuration system, core data model types, SQLite persistence layer with full CRUD operations, and pricing system for LLM cost calculation. This provides the storage and data foundation for all subsequent features.

## Motivation

PetalTrace requires a robust foundation layer to store and query trace data from PetalFlow workflows and OpenTelemetry-instrumented LLM applications. The SQLite store provides embedded persistence without external dependencies, while the pricing system enables cost tracking across different LLM providers.

```go
type TraceStore interface {
    Close() error

    // Run operations
    CreateRun(ctx context.Context, run *Run) error
    GetRun(ctx context.Context, id string) (*Run, error)
    UpdateRun(ctx context.Context, run *Run) error
    DeleteRun(ctx context.Context, id string) error
    ListRuns(ctx context.Context, opts ListRunsOptions) ([]Run, string, error)
    UpdateRunAggregates(ctx context.Context, id string) error

    // Span operations
    CreateSpan(ctx context.Context, span *Span) error
    CreateSpanBatch(ctx context.Context, spans []*Span) error
    GetSpan(ctx context.Context, id string) (*Span, error)
    GetSpanTree(ctx context.Context, runID string) ([]*Span, error)
    GetSpansByKind(ctx context.Context, runID string, kind SpanKind) ([]*Span, error)
    UpdateSpan(ctx context.Context, span *Span) error

    // FTS operations
    IndexSpanText(ctx context.Context, spanID, promptText, completionText string) error
    SearchSpans(ctx context.Context, query string, limit int) ([]*Span, error)

    // Diff operations
    CreateDiff(ctx context.Context, diff *RunDiff) error
    GetDiff(ctx context.Context, id string) (*RunDiff, error)
    GetDiffByRuns(ctx context.Context, baseRunID, compareRunID string) (*RunDiff, error)

    // Pricing operations
    GetPricing(ctx context.Context, provider, model string) (*PricingEntry, error)
    UpsertPricing(ctx context.Context, entry *PricingEntry) error
    ListPricing(ctx context.Context) ([]PricingEntry, error)

    // Maintenance
    GetStats(ctx context.Context) (*StoreStats, error)
    GarbageCollect(ctx context.Context, opts GCOptions) (*GCResult, error)
}
```

## Technical Specification

### Data Schemas / Types

#### SQLite Schema
```sql
CREATE TABLE runs (
    id TEXT PRIMARY KEY,
    workflow_id TEXT,
    workflow_name TEXT NOT NULL,
    workflow_version TEXT,
    source_kind TEXT NOT NULL DEFAULT 'otlp',
    status TEXT NOT NULL DEFAULT 'running',
    started_at TEXT NOT NULL,
    completed_at TEXT,
    duration_ms INTEGER DEFAULT 0,
    graph_snapshot TEXT,
    input_snapshot TEXT,
    config_snapshot TEXT,
    total_tokens TEXT NOT NULL DEFAULT '{}',
    estimated_cost TEXT NOT NULL DEFAULT '{}',
    node_count INTEGER DEFAULT 0,
    error_count INTEGER DEFAULT 0,
    tags TEXT,
    trigger_source TEXT,
    parent_run_id TEXT,
    starred INTEGER DEFAULT 0,
    created_at TEXT NOT NULL
);

CREATE TABLE spans (
    id TEXT PRIMARY KEY,
    run_id TEXT NOT NULL,
    parent_id TEXT,
    trace_id TEXT NOT NULL,
    kind TEXT NOT NULL,
    name TEXT NOT NULL,
    status TEXT NOT NULL DEFAULT 'ok',
    started_at TEXT NOT NULL,
    completed_at TEXT,
    duration_ms INTEGER DEFAULT 0,
    node_data TEXT,
    llm_data TEXT,
    tool_data TEXT,
    edge_data TEXT,
    error_data TEXT,
    attributes TEXT,
    created_at TEXT NOT NULL,
    FOREIGN KEY (run_id) REFERENCES runs(id) ON DELETE CASCADE
);

CREATE VIRTUAL TABLE spans_fts USING fts4(
    span_id,
    prompt_text,
    completion_text,
    content="spans"
);
```

## Usage Examples

### Creating and Querying Runs
```go
store, _ := store.NewSQLiteStore(store.SQLiteOptions{Path: "trace.db"})

// Create a run
run := &store.Run{
    ID:           store.NewID(),
    WorkflowName: "my-workflow",
    Status:       store.RunStatusRunning,
    StartedAt:    time.Now(),
}
store.CreateRun(ctx, run)

// List runs with filtering
runs, cursor, _ := store.ListRuns(ctx, store.ListRunsOptions{
    WorkflowName: "my-workflow",
    Status:       store.RunStatusCompleted,
    Limit:        50,
})
```

### Computing LLM Costs
```go
pricing, _ := pricing.LoadBuiltin()

cost := pricing.ComputeCost("anthropic", "claude-sonnet-4-20250514",
    1000,  // input tokens
    500,   // output tokens
    200,   // cache read tokens
    0,     // cache write tokens
)
// cost ≈ $0.0106
```

## Integration Notes

This foundation layer integrates with:
- **PetalFlow**: The `petalflow.run.id` and `petalflow.workflow.*` attributes are used to correlate spans
- **Iris**: The `gen_ai.*` semantic conventions from OTel are parsed for LLM span data

The store interface is designed to be consumed by:
- The OTLP collector (Phase 2)
- The HTTP API (Phase 4)
- The CLI commands (Phase 3)
